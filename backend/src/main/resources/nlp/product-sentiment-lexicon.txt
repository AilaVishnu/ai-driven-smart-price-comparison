# Product-review sentiment lexicon, authored for this project.
#
# Format:  term<TAB>weight     with weight in [-5, 5]
#
# Written specifically for e-commerce review language rather than borrowed from
# a general-purpose word list. That matters: in product reviews "cheap" usually
# means shoddy rather than affordable, "returned" is a complaint, and "worth"
# is praise. A general lexicon scores all three wrongly. Authoring it here also
# keeps the project free of third-party dataset licensing questions.
#
# Lines beginning with # are comments.
